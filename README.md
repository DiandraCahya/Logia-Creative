## 📌 Gambaran Umum Proyek

Repositori ini memuat kode sumber website **Company Profile LOGIA CREATIVE**. Website ini dirancang dan dikembangkan sebagai media representasi digital interaktif untuk memperkenalkan agensi, memaparkan nilai bisnis, serta memvisualisasikan solusi kreatif dan teknologi yang diusung.

### Latar Belakang
Aktivitas bisnis saat ini sangat bergantung pada kehadiran media digital yang kuat. Bagi pelaku usaha, sekadar memiliki produk yang baik belum cukup tanpa didukung identitas visual yang menarik serta sistem bisnis yang efisien. Di sisi lain, banyak UMKM, brand lokal, startup, hingga organisasi masih menghadapi kendala sumber daya dan keahlian dalam mengelola aspek kreatif sekaligus teknologi secara terpadu.

**LOGIA CREATIVE** hadir sebagai *Creative & Technology Agency* yang mengintegrasikan kreativitas visual dan solusi teknologi modern guna menjembatani kesenjangan tersebut.

---

## 🎯 Tujuan Pembuatan Website

Website company profile ini dibangun dengan beberapa tujuan utama:

1. **Digital Presence & Brand Identity**  
   Menjadi etalase digital utama yang mencerminkan karakter, visi, dan profesionalisme LOGIA CREATIVE.
2. **Edukasi & Informasi Solusi Terpadu**  
   Menyampaikan informasi komprehensif mengenai integrasi dua domain utama: *Creative Solutions* (branding & konten) dan *Technology Solutions* (web development & otomatisasi sistem bisnis).
3. **Membidik Segmentasi Pasar yang Tepat**  
   Menjelaskan relevansi solusi terhadap kebutuhan target pasar:
   - **UMKM & Brand Lokal:** Kebutuhan identitas visual, kemasan, konten medsos, dan media web dasar.
   - **Startup & Growing Businesses:** Kebutuhan UI/UX design, web development, kampanye kreatif, serta automasi alur kerja/pelaporan.
   - **Organisasi & Penyelenggara Acara:** Kebutuhan media promosi acara, *brand activation*, sistem registrasi, dan monitoring.
4. **Demonstrasi Kapabilitas Teknis & Desain**  
   Menampilkan implementasi desain web modern dengan performa tinggi, UI/UX interaktif, serta animasi yang halus.

## 🧭 Profil & Solusi yang Ditampilkan

Website ini memuat informasi mengenai dua rumpun kapabilitas utama LOGIA CREATIVE:

### 1. Creative Solutions
- **Brand Identity & Visual Design:** Pengembangan identitas merek, logo, panduan visual, dan desain kemasan.
- **Social Media & Content Production:** Produksi konten visual, strategi media sosial, dan materi komunikasi digital.
- **Creative Campaign & Brand Activation:** Kampanye kreatif terarah dan materi aktivasi merek.

### 2. Technology Solutions
- **UI/UX Design & Web Development:** Perancangan antarmuka pengguna interaktif dan pengembangan website modern.
- **Reporting & Workflow Automation:** Digitalisasi pencatatan, sistem pelaporan, dan otomatisasi alur kerja bisnis.

## 🛠️ Tech Stack

Website ini dibangun menggunakan stack modern:

- **Framework:** [Next.js 16 (App Router)](https://nextjs.org/)
- **Library UI:** [React 19](https://react.dev/)
- **Bahasa:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animasi & Interaksi:**
  - [Framer Motion](https://www.framer.com/motion/) — Transisi komponen & animasi UI
  - [GSAP](https://greensock.com/gsap/) — Animasi interaktif kompleks
- **Linter:** ESLint

## 🚀 Panduan Menjalankan Proyek

### Prasyarat
- [Node.js](https://nodejs.org/) versi 18.x atau yang lebih baru
- Package manager: `npm`, `yarn`, `pnpm`, atau `bun`

### Langkah Instalasi

1. **Clone repositori:**
   ```bash
   git clone https://github.com/DiandraCahya/Logia-Creative.git
   cd Logia-Creative
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. Buka peramban dan akses alamat:
   ```
   http://localhost:3000
   ```

---

## 📜 Perintah yang Tersedia

| Perintah | Deskripsi |
|---|---|
| `npm run dev` | Menjalankan server lokal untuk tahap pengembangan (disertai Hot Module Replacement) |
| `npm run build` | Melakukan kompilasi dan optimasi kode untuk tahap produksi |
| `npm run start` | Menjalankan server produksi dari hasil build |
| `npm run lint` | Menjalankan static code analysis menggunakan ESLint |
